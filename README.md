# Drug–Pathogen Research Portfolio

## This repository documents my independent learning and computational research at the intersection of biomedical science, drug research, and antimicrobial resistance (AMR).

It brings together data analysis, scientific literature review, and self-directed study in microbiology, molecular techniques, and pharmacology.

# Projects

 **1. Blood–Brain Barrier (BBB) Permeability Prediction**

An independent computational project investigating the prediction of blood–brain barrier permeability using molecular features and machine-learning approaches.

- Molecular descriptor analysis
- Morgan fingerprint-based molecular representation
- Classification models and performance evaluation
- Applicability-domain analysis

Notebook: See the BBB analysis notebook in this repository.

**2. Antimicrobial Resistance (AMR) Data Analysis**

An independent data-analysis project involving WHO antimicrobial resistance data and scientific reporting.

- Exploration and analysis of AMR-related data
- Data processing and interpretation using Python
- Review of WHO reports and relevant scientific evidence
- Scientific communication of antimicrobial resistance issues

Notebook: "whoamr_data.ipynb"

Self-Study and Learning
